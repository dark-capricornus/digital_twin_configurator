What you'll do in each step
①
Setup — this screen
Name the package. No files needed — you're starting from nothing.
②
Define — build hierarchy & blocks
Add areas, machines and block templates manually. Import a tag list or parameter spec at any point.
③
Map — connect tags to properties
Link SCADA/PLC tags to each block property. Confirm units, ranges and alarm thresholds.
④
Publish — export .dt-pkg
Validate and export the package for deployment or handoff.
Import anytime
Starting blank doesn't mean doing everything manually. You can import a tag list or parameter spec at any point in step ②.
